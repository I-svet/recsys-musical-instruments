# Воспроизводимость

Проверены 81 тест и все ячейки основного ноутбука.

- Тесты проверяют формулы моделей, градиенты, временные ограничения, общий отбор рекомендаций и сохранение результатов.
- Отдельно проверяется, что изменение файла в models/ меняет контрольную сумму исходников эксперимента.
- experiments.ipynb выполнен с начала до конца. В нём сохранены таблицы, графики и результаты поиска параметров.
- Метрики отчёта пересчитываются по сохранённым спискам рекомендаций. Файлы защищены контрольными суммами.

```bash
python -m pytest -q
python scripts/verify_report.py reports
```

Окружение, параметры и контрольная сумма исходников записаны в [provenance.json](../reports/provenance.json). Контрольная сумма включает реализации из models/. При изменении исходников старые этапы обучения не используются.

report_manifest.json хранит контрольные суммы отчёта, audit/manifest.json контрольные суммы журналов и рекомендаций. Исходники Python сохраняются с окончаниями строк LF. Файлы отчёта сохраняют свои байты при копировании репозитория. Версии библиотек закреплены в requirements.txt и requirements.lock.txt. Численные результаты на разных платформах могут немного отличаться.
