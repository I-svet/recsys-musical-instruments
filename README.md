Пять моделей для персональных рекомендаций: ItemKNN, ALS для явных оценок, EASE, FM с метапризнаками и timeSVD++. Для сравнения ещё есть MostPopular, FM только с ID и SVD++ без учёта времени.

## Данные

[Amazon Review Data 2018, UCSD](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/), категория Musical Instruments. Загрузчик получает оценки и метаданные из первоисточника и проверяет SHA256.

Из 1 512 530 строк удалены 41 966 повторных пар пользователь-товар. Сохраняется первый отзыв по времени, при совпадении дат выбирается меньший номер исходной строки. Из обучающей части по очереди удаляются пользователи и товары с менее чем пятью взаимодействиями. После отбора осталось 17 702 пользователя и 7 329 товаров.

| Часть | Период UTC | Взаимодействия |
|---|---|---:|
| Обучение | до 2017-04-17 | 144 036 |
| Проверка | 2017-04-17 ≤ t < 2017-12-08 | 5 547 |
| Тест | t ≥ 2017-12-08 | 3 741 |
| Всего | | 153 324 |

Метаданные содержат названия 7 324 товаров. Для остальных пяти в примерах используется ASIN.

## Протокол сравнения

Релевантный товар имеет будущую оценку ≥4. Из полного каталога убираются уже оценённые товары, затем выбираются 10 рекомендаций. История берётся на начало периода.

Параметры и число эпох подбираются по NDCG@10 на проверочной части. Потом модель обучается на обучающей и проверочной частях вместе. Начальные значения генератора случайных чисел: 17, 42 и 2026. Также считаются Recall, Precision, MAP, RMSE, покрытие каталога, время и память.

Основные метрики считаются по 1 702 пользователям с положительными тестовыми оценками внутри каталога. `Recall_all_future@10` также учитывает товары вне каталога и рассчитывается по 2 493 пользователям. В каталоге доступны 57,37% их будущих положительных событий.

FM использует число и среднее прошлых оценок, возраст истории и дату запроса. Признаки и история timeSVD++ учитывают только предыдущие дни. Названия товаров нужны для показа рекомендаций.

## Запуск

CPython 3.12, процессор, желательно 16 ГБ памяти. Версии библиотек указаны в `requirements.lock.txt`. В эксперименте использованы четыре потока.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.lock.txt
python -m pip install --no-deps --no-build-isolation -e .
python -m pytest -q
python scripts/reproduce.py
```

Скрипт скачивает данные, готовит выборку, обучает модели и делает отчёт. Файлы запусков: `artifacts/benchmark`, новый отчёт: `reports-local`. Готовые результаты лежат в `reports`.

Поэтапный запуск:

```bash
python -m recsys download --metadata
python -m recsys prepare
python -m recsys metadata
python -m recsys run --stage pilot
python -m recsys run --stage tune
python -m recsys run --stage final
python -m recsys report --output reports-local
python scripts/plot_tradeoff.py reports-local
python scripts/verify_report.py reports-local
```

Короткий запуск с одной конфигурацией и максимум двумя эпохами:

```bash
python scripts/reproduce.py --config configs/smoke.json --output artifacts/smoke --report reports-smoke
```

Проверка опубликованного отчёта без скачивания данных и установки зависимостей:

```bash
python scripts/verify_report.py reports
```

Готовые этапы повторно не запускаются. После изменения кода, данных, окружения или параметров нужен новый `--output`.

Top-10 для внутреннего ID пользователя:

```bash
python -m recsys recommend --model artifacts/benchmark/final/ease/42/model.pkl --user 0
```

Загружайте только собственные доверенные pickle-файлы моделей.

## Реализация

Обучение, расчёт оценок и отбор рекомендаций находятся в `src/recsys`. NumPy и SciPy нужны для линейной алгебры, PyTorch для тензоров, автоматических градиентов и Adam. Тесты запускаются на Windows и Linux.
