# Воспроизводимость

- 78 тестов проходят локально и в [автоматических проверках на Windows и Linux](https://github.com/I-svet/recsys-musical-instruments/actions/runs/39321234898).
- Подготовка данных в чистой копии репозитория воспроизводит SHA256 всех шести файлов выборки и отображений ID.
- Независимый пересчёт подтверждает метрики 18 финальных прогонов, средние, стандартные отклонения и три доверительных интервала.
- Проверены контрольные суммы 168 файлов отчёта и 152 вложенных файлов аудита, включая проверку после копирования репозитория.

```bash
python -m pytest -q
python scripts/verify_report.py reports
```

SHA256 исходников при обучении: `a129adf4f8fbeea221ae1761cff534375c8b525cd8d3b98ae934b962e63e8ed3`. Окружение, конфигурация и идентификатор эксперимента записаны в [provenance.json](../reports/provenance.json).

Тесты проверяют математические эталоны, временную изоляцию, градиенты, точность ускоренного расчёта оценок, разрешение равных оценок при отборе рекомендаций, сохранение моделей и сквозной эксперимент. Изменение тестовых данных в интеграционном тесте не меняет выбор конфигурации на проверочной части.

`report_manifest.json` хранит контрольные суммы отчёта, `audit/manifest.json` контрольные суммы журналов и рекомендаций. Правило Git `reports/** -text` сохраняет их байты при копировании репозитория. Версии зависимостей закреплены в `requirements.lock.txt`. Численные результаты на разных версиях BLAS и платформах могут отличаться.
